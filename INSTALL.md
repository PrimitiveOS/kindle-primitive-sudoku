# Install Primitive Sudoku

When available in Primitive Store, open the listing and choose Get. Open Primitive Sudoku from the launcher grid.

For a local USB test, extract the package for your Kindle, copy the `sudoku` and `documents` folders to user storage,
eject, and open Primitive Sudoku from Primitive Launcher. The app uses the launcher's fonts. The Done button returns you
to the launcher.
